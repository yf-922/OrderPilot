## 可用结论与简历措辞

在3条四组完整运行的八轮同源样本中，单独启用三级压缩使累计输入Token降低52.24%；在相同压缩器上启用Jev再降低11.87%，两者组合较基线降低57.90%，Turn6+单请求峰值降低66.07%。压缩构建均值5.8ms，网关网络均值8919.2ms。

不能据此声称Jev普遍提高准确率或主流程P95低于2秒；两条E轨迹出现额外查询，另有一次历史网关超时，必须同时披露。

简历保守示例：针对电商客服长对话中工具载荷膨胀及取消确认开销，设计状态槽锚定、历史载荷脱水与Token预算压缩，结合确定性Jev工具路由和确认直通；在四组消融中，3条完整配对八轮场景的累计输入降低57.90%、Turn6+单请求峰值降低66.07%。此结果为小样本线上验证，不作为生产总体SLA或准确率结论。
